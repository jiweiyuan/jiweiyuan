## Selected Work

### Agent Runtimes

- **[Termio](https://github.com/termio-sh/termio)** · 430+ ★ · [termio.sh](https://termio.sh) — terminal-first development environment for agentic coding: a runtime and multiplexer built for CLI/TUI agents rather than adapted from tmux
- **[Zypher Agent](https://github.com/corespeed-io/zypher-agent)** · 330+ ★ — minimal agent framework with full control over tools, providers, and execution flow

### Tools & Skills for Agents

- **[ACI](https://github.com/aipotheosis-labs/aci)** · 4.8k+ ★ · [aci.dev](https://www.aci.dev) — open-source tool-calling platform: 600+ integrations behind direct function calling or a unified MCP server
- **[Skilluse](https://github.com/skilluse/skilluse)** · 55+ ★ · [skilluse.dev](https://skilluse.dev) — agent skills registry and CLI: publish, discover, and install skills across Claude Code, Codex, Cursor, and others
- **[MCP Gateway](https://github.com/aipotheosis-labs/gate22)** · 175+ ★ — gateway and control plane governing which tools agents may call, and how those calls are audited

### Access & Connectivity

- **[SigCLI](https://github.com/sigcli/sigcli)** · 290+ ★ · [sigcli.ai](https://sigcli.ai) — authentication CLI and proxy: give agents access, not your credentials
- **[WeChat Bot](https://github.com/corespeed-io/wechatbot)** · 640+ ★ · [wechatbot.dev](https://wechatbot.dev) — WeChat iLink bot SDK for AI agents
- **[Tunelo](https://github.com/jiweiyuan/tunelo)** · 425+ ★ · [tunelo.net](https://tunelo.net) — QUIC-based tunnel for exposing localhost, faster than frp, cloudflared, and ngrok
- **[RunBrowser](https://github.com/termio-sh/runbrowser)** · [runbrowser.com](https://runbrowser.com) — Chrome extension and CLI that drive your real, logged-in browser over CDP

Also maintaining [TTS CLI](https://github.com/jiweiyuan/ttscli), speech synthesis from the terminal, and [Feedar](https://github.com/jiweiyuan/feedar), an RSS reader built for agents.
